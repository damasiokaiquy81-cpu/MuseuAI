# 🖼️ MuseuAI — sua galeria em formato de museu

Um site de portfólio para artistas: as obras aparecem numa galeria estilo museu,
cada obra tem botão de **orçamento pelo WhatsApp**, **avaliação com estrelas**,
**link copiável** que abre o site direto na obra, e a página inicial mostra
**quem é o artista**, a **média geral das avaliações** e as **3 mais bem avaliadas**
(se ainda não tem avaliações, mostra 3 obras aleatórias como destaque).

Não precisa instalar nada: é HTML + CSS + JavaScript puro.

---

## ▶️ Como abrir

Dê dois cliques em `index.html`. É só isso.
(Se publicar na internet, os links copiáveis passam a funcionar ainda melhor.)

---

## ✏️ Como deixar com a sua cara

### 1. Suas informações → `js/config.js`
| Campo | O que é |
|---|---|
| `nomeArtista` | Seu nome (aparece no "Olá! Eu sou…") |
| `funcao` | Suas áreas, ex.: "Pintora · Ilustradora" |
| `bio` | Texto de apresentação |
| `whatsapp` | **Só números, com DDI + DDD** — ex.: `5511999999999` |
| `mensagemObra` | Mensagem que o cliente manda ao pedir orçamento (use `{obra}`) |
| `fotoArtista` | Sua foto (coloque o arquivo na pasta `artes/`) |
| `email`, `instagram`, `cidade` | Aparecem no rodapé |

### 2. Suas obras → `js/data.js`
Para cada obra você informa: `id` (nome único, sem espaços), `titulo`, `arquivo`
(coloque a imagem na pasta `artes/`), `ano`, `tecnica`, `descricao` e
`largura`/`altura` da imagem em pixels.

> As 8 obras de exemplo usam arquivos `.svg` desenhados à mão —
> são só demonstração. Substitua pelas suas imagens (`.jpg`, `.png`, `.webp`).

### 3. Salve e recarregue a página. Pronto!

## ⭐ Como funcionam as avaliações

- Qualquer visitante entra na obra e avalia com **1 a 5 estrelas**
  (nome e comentário são opcionais).
- O site soma tudo e mostra no início: **média geral**, **número de avaliações**
  e a seção **"Mais bem avaliadas"** (top 3).
- **Sem nenhuma avaliação ainda?** A seção de destaques mostra
  **3 obras aleatórias** para não ficar vazio.

### Modo local (padrão)
As avaliações ficam salvas **no navegador de quem avaliou**. Ótimo para testar,
mas o dono não vê o que os visitantes avaliaram em outros aparelhos.

### Modo online (recomendado para publicar de verdade)
Reúne as avaliações de **todos** os visitantes num banco gratuito do Supabase:

1. Crie uma conta grátis em [supabase.com](https://supabase.com) e um projeto novo.
2. Vá em **SQL Editor**, cole o código abaixo e clique em **Run**:

```sql
create table if not exists avaliacoes (
  id bigint generated by default as identity primary key,
  obra text not null,
  nota int not null check (nota between 1 and 5),
  nome text default '',
  comentario text default '',
  criado_em timestamptz not null default now()
);

alter table avaliacoes enable row level security;

create policy "qualquer pessoa pode ler"
  on avaliacoes for select using (true);

create policy "qualquer pessoa pode avaliar"
  on avaliacoes for insert with check (true);
```

3. Em **Project Settings → API**, copie a **Project URL** e a **anon public key**.
4. Cole as duas em `js/config.js`, dentro de `supabase:` e salve.

Pronto — todas as avaliações dos visitantes agora ficam salvas para você.

## 🔗 Como funciona o link copiável

Ao abrir uma obra, tem o botão **"Copiar link desta arte"**. O link copiado é
algo como `seusite.com/#/obra/aurora` — quem abrir cai **direto na obra**, com
os botões de WhatsApp, avaliação e orçamento. Serve para:

- o **dono** enviar para clientes pedir avaliação ou fechar venda;
- o **cliente** compartilhar a arte que comprou/quer.

## 🚀 Como publicar de graça

Escolha qualquer uma (leva 2 minutos):

- **Netlify Drop** → [app.netlify.com/drop](https://app.netlify.com/drop):
  arraste a pasta inteira do site para a página.
- **GitHub Pages** → suba os arquivos num repositório e ative Pages.
- **Vercel** → [vercel.com](https://vercel.com): importe a pasta.

Depois de publicar, copie o link de uma obra pelo botão e espalhe! 🎨
